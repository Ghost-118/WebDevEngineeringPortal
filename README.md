# WebDevEngineeringPortal

Portal web técnico desarrollado en ASP.NET Core (Razor Pages), enfocado en la ingeniería de software y la demostración interactiva de lenguajes de programación modernos.

## 🚀 Tecnologías y Arquitectura

El proyecto está construido bajo una arquitectura modular y limpia orientada a servicios web backend:
* **Backend:** C#, ASP.NET Core (Razor Pages)
* **Frontend:** HTML5, CSS3, JavaScript
* **Control de Versiones:** Git & GitHub (con configuración de lenguajes optimizada mediante `.gitattributes`)

## 📂 Estructura del Proyecto

* `Pages/` — Páginas Razor principales que contienen las vistas y la lógica de interfaz de usuario.
* `Controllers/` — Controladores encargados de la gestión de rutas y lógica de negocio intermedia.
* `Models/` — Clases de datos y modelos estructurados para las fichas técnicas.
* `wwwroot/` — Recursos estáticos (hojas de estilo, scripts y elementos visuales).
